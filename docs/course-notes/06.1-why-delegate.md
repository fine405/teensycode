# 6.1 Why delegate

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/why-delegate)

Delegation is useful when a task has a clean handoff and the parent benefits
from not retaining the entire work trace.

It addresses three failures that message pruning alone cannot prevent:

1. Context pollution from broad exploration.
2. Lost focus during long, multi-concern runs.
3. Over-broad capabilities during read-only work.

The parent keeps planning, ambiguity, and architectural decisions. Explorers
return bounded research summaries. Executors receive precise implementation
instructions and a constrained trust slice. Small or tightly sequential work
stays in the parent because a fresh subagent has startup cost and latency.

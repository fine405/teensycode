# 5.4 Cache control with DeepSeek

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/cache-control) ·
[DeepSeek context caching](https://api-docs.deepseek.com/guides/kv_cache)

The course's `cacheControl: { type: "ephemeral" }` marker is specific to
providers that expose explicit prompt-cache breakpoints. Direct DeepSeek does
not accept that option: context caching is enabled automatically for all API
users and matches repeated, fully identical prompt prefixes.

This implementation therefore keeps the stable system/user prefix produced by
`prepareCall`, avoids sending an unsupported provider option, and logs AI SDK's
`usage.cachedInputTokens`. The DeepSeek provider maps that value from
`prompt_cache_hit_tokens` in the API response.

Recent messages still change on every step and are cache misses. Older shared
prefixes can become cache hits without application code.

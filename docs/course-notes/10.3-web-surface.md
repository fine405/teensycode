# 10.3 Web surface boundary

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/web-surface)

The agent consumes a prompt plus optional message history and emits the same
stream chunks regardless of surface. A web layer adds concerns outside that
boundary:

- persist messages by session before and after a run;
- carry stream chunks over SSE or another HTTP streaming transport;
- render tool calls/results as components rather than stderr lines;
- turn `askUser` into controls that submit the next user message;
- resume or reconstruct sessions after disconnects.

Authentication, storage, HTTP responses, and React components must not create
`isWeb` branches inside the agent. A future web adapter should consume the
headless harness factory and `fullStream` exactly as the CLI renderer does.

# 8.2 Approval config and policy events

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/approval-config)

Approval config answers who decides for the entire session:

- `interactive`: safe commands run; the user decides on the rest.
- `background`: unattended execution accepts all commands.
- `delegated`: a parent grants a narrow command trust slice.

Policy events answer what rules apply to each tool call. They can block a
protected path, modify an input, or pass it through regardless of session mode.
The two layers combine: config chooses the operational posture, while event
subscribers enforce project-specific defense in depth.

The event layer belongs to Module 11. Its first safety example should block
writes to environment files even when the session config would otherwise allow
the operation.

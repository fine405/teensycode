# 7.4 Lifecycle failure gates

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/hard-won-lessons)

Five production failure modes and their gates:

1. Probe a reconnected handle before trusting it; restore when the probe fails.
2. Fetch fresh expiry data for control flow; cached values are display-only.
3. Exclude status polling, probes, and health checks from activity tracking.
4. Auto-resume only on initial entry; reconnects join an already active sandbox.
5. Treat provider state as truth; database and client state are caches.

These gates compose. A stale handle combined with false polling activity can
keep an unusable sandbox billed until hard expiry, while divergent state plus
automatic resume can create duplicate sandboxes. Cloud lifecycle code needs all
five checks, not only the first failure encountered in development.

# 4.4 Cloud implementation

[Course lesson](https://vercel.com/academy/build-ai-agent-harness/cloud-implementation)

No cloud backend is added in this checkpoint. The existing `Sandbox` interface
already has the required shape: cloud implementations replace local calls with
network calls and may opt into `expiresAt` and `snapshot()`.

Key tradeoffs:

- Local is fastest and persistent but provides no isolation.
- just-bash is copy-on-write and free, but its shell is simulated.
- Cloud provides a real isolated VM at the cost of latency, per-minute billing,
  hard expiry, and explicit persistence.

`expiresAt` is optional because local and in-memory sandboxes do not expire.
`snapshot()` is optional because only a backend with durable external storage
can promise restoration semantics.
